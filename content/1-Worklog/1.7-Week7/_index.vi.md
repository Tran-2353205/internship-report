### Kết quả đạt được tuần 7:

* Nắm được các dịch vụ Database của AWS và ứng dụng thực tế của từng dịch vụ:
  * Amazon RDS
  * Amazon Aurora
  * Amazon Redshift
  * Amazon ElastiCache

* Hoàn thành các bài thực hành của Module 06:
  * Triển khai database trên Amazon RDS
  * Sao lưu và khôi phục dữ liệu
  * Thực hành các câu lệnh SQL
  * Tìm hiểu quy trình di chuyển dữ liệu bằng AWS DMS và AWS SCT

* Hoàn thành thiết kế kiến trúc backend của hệ thống Quản lý thư viện, xác định các thành phần chính và cách chúng tương tác với nhau.

* Hoàn thiện tài liệu thiết kế RESTful API cho các chức năng cốt lõi của hệ thống, chuẩn bị triển khai bằng Django REST Framework.

* Thống nhất công nghệ sử dụng cho backend (Django, Django REST Framework, Django ORM, Docker) và thiết lập môi trường phát triển Django cục bộ, sẵn sàng bắt đầu triển khai trong tuần tiếp theo.
