### Kết quả đạt được tuần 7:

* Nắm được cách cấu hình Amazon Route 53 để quản lý DNS: Hosted Zone, các loại Record, Routing Policy.

* Thành thạo sử dụng AWS CLI để thao tác với các dịch vụ AWS qua dòng lệnh và viết script tự động hóa cơ bản.

* Hiểu được cách sử dụng AWS Secrets Manager để lưu trữ, quản lý và tự động xoay vòng thông tin xác thực (credentials) cho ứng dụng Backend.

* Rà soát và sửa các lỗi logic, xử lý ngoại lệ trong code Backend, refactor lại một số phần cho rõ ràng và dễ bảo trì hơn.

* Kiểm tra hiệu năng truy vấn, xử lý các lỗi phát sinh khi tích hợp với Frontend, hoàn thành review code cùng nhóm.
