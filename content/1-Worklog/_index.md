During my internship from **08/06/2026 to 31/07/2026**, I participated in the **First Cloud AI Journey** program organized by the AWS Study Group, taking on the role of **Backend Developer** within our team project. Throughout the **08-week internship**, I studied and practiced the fundamental services of Amazon Web Services (AWS) while applying the knowledge I gained to design, build, and integrate the backend of a **Library Management Website**.

In addition to completing the lessons and hands-on labs provided by the program, I took part in the full software development lifecycle from a backend perspective, including requirements analysis, database design, API design and implementation, backend testing, and integration with the AWS infrastructure.

The work completed each week is summarized as follows:

**Week 1:** [Pre-onboarding preparation: development environment setup and backend fundamentals review](1.1-week1/)

**Week 2:** [Introduction to the First Cloud AI Journey program, Module 01, and project idea proposal](1.2-week2/)

**Week 3:** [Module 02, project discussion and topic selection, Proposal development](1.3-week3/)

**Week 4:** [Module 03, business analysis, and Software Requirements Specification (SRS) development](1.4-week4/)

**Week 5:** [Module 04 and Use Case Diagram design](1.5-week5/)

**Week 6:** [Module 05 and database design (ERD)](1.6-week6/)

**Week 7:** [Module 06, backend architecture design, and API documentation](1.7-week7/)

**Week 8:** [Backend project setup and implementation of core backend functionalities](1.8-week8/)
